# About
This is code is related to the paper: "Exploring microbiome diversity of distant anatomical sites of the female body" conducted in the work of Sandra Jablonska, Alex Kula, and Catherine Putonti

## Code Details
This repo includes three scripts to generate 1) Dada2 graphs for each respective anatomical site 2) Alpha diversity of samples 3) Beta diversity of samples 

### Data for DADA2
* Left and right reads from microbiome samples collected from Loyola University Chicago. 
* Additional metagenome tables if including samples from different anatomical sites
* urobiome color scheme package

### Packages for PcoA (R)
* vegan
* ggplot
